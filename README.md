# Titanic EDA Project

This project performs Exploratory Data Analysis (EDA) on the Titanic dataset.

## Objectives
- Data cleaning and preprocessing
- Data visualization
- Finding patterns affecting survival

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Key Insights
- Females had higher survival rate
- First class passengers survived more
- Fare is related to survival
